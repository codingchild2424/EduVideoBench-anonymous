## 작성 가이드

### 파일명 규칙
```
YYYY-MM-DD_<topic>.md
```

### 필수 섹션
1. **개요**: 무엇을 했는지 간단히
2. **주요 결정 사항**: 중요한 기술적/설계적 결정과 이유
3. **구현 내용**: 구체적으로 무엇을 구현했는지
4. **향후 작업**: 남은 작업 또는 개선 사항
5. **참고 자료**: 관련 문서/링크

### 예시 템플릿

```markdown
# 개발 기록: [제목]

**날짜**: YYYY-MM-DD
**작성자**: [이름]
**버전**: X.Y.Z

---

## 개요

[1-2문장으로 요약]

## 주요 결정 사항

### 1. [결정 1]
- 배경
- 선택지
- 최종 결정 및 이유

## 구현 내용

[코드 예시, 구조 설명 등]

## 향후 작업

- [ ] 작업 1
- [ ] 작업 2

## 참고 자료

- [링크 1](url)
```
